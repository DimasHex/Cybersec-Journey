## 🎯 Motivasi Bergabung dengan TISS

Saya bergabung dengan **TISS** karena ingin memperluas pengetahuan dan kemampuan saya di bidang Cyber Security melalui proses belajar yang lebih terarah dan praktis.

Sebagai mahasiswa Informatika, saya merasa Cyber Security merupakan bidang yang menarik karena menggabungkan berbagai kemampuan seperti networking, sistem operasi, pemrograman, analisis, dan problem solving.

Saya ingin menggunakan kesempatan di TISS untuk membangun fundamental yang lebih kuat, mencoba berbagai latihan, dan memahami konsep keamanan tidak hanya dari sisi teori tetapi juga melalui praktik.

Selain meningkatkan kemampuan teknis, saya juga ingin membangun kebiasaan untuk belajar secara konsisten dan mendokumentasikan setiap perkembangan yang saya lakukan. Saya percaya bahwa proses belajar akan lebih berarti ketika setiap kesalahan, tantangan, dan pencapaian dapat dijadikan bahan evaluasi untuk berkembang.

Saya berharap selama mengikuti TISS, saya dapat bertemu dengan lingkungan yang mendorong saya untuk terus belajar, menghadapi tantangan baru, dan meningkatkan kemampuan saya secara bertahap.

Bagi saya, TISS bukan hanya tentang mencapai sebuah rank, tetapi tentang bagaimana saya dapat berkembang menjadi pribadi yang lebih kompeten, disiplin, dan siap menghadapi tantangan di dunia Cyber Security.
